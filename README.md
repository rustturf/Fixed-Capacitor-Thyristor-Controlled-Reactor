# Fixed Capacitor Thyristor Controlled Reactor (TCR) Documentation

This repository contains detailed documentation for the **LaTeX file** and the **Simulink file** related to the **Fixed Capacitor Thyristor Controlled Reactor (TCR)** project.

## Contents

- **LaTeX File**: Detailed explanation, derivations, and technical documentation of the TCR system.  
- **Simulink File**: Simulation model of the Fixed Capacitor Thyristor Controlled Reactor for analysis and study.

## Purpose

The repository aims to provide a complete reference for understanding and simulating a Fixed Capacitor TCR, useful for educational and research purposes in power systems.
